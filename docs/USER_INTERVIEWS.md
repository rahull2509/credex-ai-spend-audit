# User Interviews

## Interview 1: Seed Founder, 11-person devtools startup

Pain: Engineers expensed Cursor, Copilot, ChatGPT, and Claude independently.

Quote: "I do not want to ban tools. I want to know which duplicates are actually costing us."

Product implication: Recommendations should frame consolidation as focus, not restriction.

## Interview 2: Fractional CFO, B2B SaaS portfolio

Pain: AI subscriptions show up as small line items, so nobody reviews them until renewal.

Quote: "The annualized number matters. Monthly waste sounds small until it becomes runway."

Product implication: Results page should lead with monthly and annual savings.

## Interview 3: Engineering Manager, 24-person startup

Pain: API keys for experiments were still active after prototypes shipped.

Quote: "We need guardrails before we need another dashboard."

Product implication: API recommendations should include caps, environment split, and model routing.
